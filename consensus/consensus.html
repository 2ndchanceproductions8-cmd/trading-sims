What this book is. Every other book in the fleet bets its own board, and several of them keep reaching the same conclusion — on 2026-07-28 the fleet placed 94 tickets carrying just 41 distinct opinions, 2.29 books per pick. Each duplicate pays the full ~4.42% hold again for a view the fleet already held. This book takes each distinct opinion exactly once, at a flat 2% stake.

What it is not. It is not a better model and it cannot create an edge — every ticket here still pays the hold once, so its expected return per dollar is the same as its sources. It also is not a consensus signal: agreement between these bots is largely tautological, and measured on the archive it did not predict outcome (slope +0.080, SE 0.085, t = +0.94 — null). Every ticket records how many books agreed so that question keeps being asked forward.
